# 作業の進め方

## エージェントの作業方針

- Issueの目的と完了条件が明確な場合は、自律的に調査・実装・テストを進める。

- 作業前に既存コード、関連Issue、テスト、リポジトリ規約を確認する。

- Issueの範囲を超える機能追加や無関係なリファクタリングを行わない。

- 大きな設計変更、破壊的操作、機密情報に関わる操作は事前に確認する。

- 実装中に発見した別件の問題は、必要に応じて独立したIssueとして整理する。

- テストを実行できない場合は、成功したと報告せず理由を明示する。

- 作業完了時は、変更概要、テスト結果、PRのURL、Linear連携状態、残存課題を簡潔に報告する。
