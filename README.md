# Agent Common Instructions

Portable personal instructions for AI coding agents, with setup and sync guidance.

## Contents

- [AGENTS.md](./AGENTS.md): the complete, standalone common instruction source.

## Purpose

This repository keeps personal instructions for AI coding agents in one public, versioned source. The instructions are intended for the owner's environments and should not be committed into other projects as shared repository policy.

The source is plain Markdown and is not tied to a specific agent. Setup and synchronization tooling can be added separately while keeping this file portable.

## Applying the instructions

Use these instructions as defaults when they fit the task. Instructions and shared conventions in the target repository take precedence whenever they conflict.

The Linear and GitHub workflow rules in the source apply only when the work uses Linear. They do not require creating or linking an issue when Linear is not in use.

## Source of truth

`AGENTS.md` is the single canonical instruction document. Keep it independently readable; avoid splitting or duplicating its contents across files.
